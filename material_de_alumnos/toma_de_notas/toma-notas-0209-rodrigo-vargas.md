# User stories

la tarjeta de una user story

1. El relato
2. Criterios de aceptación
3. Pruebas de usuario
4. Estimación

Previos a escribir una historia:
- Rol: El tipo de usuario que interactua con el sistema y tiene necesidades definidas. Es un perfil.
- Epica: Una necesidad grande, todavia dificil de estimar, que en algun momento se va a partir en varias US más chicas.
- Tema: Un conjunto de epicas o US relacionadas entre si, que suelen agruparse para planificarse juntas.

User Stories:
- Yo como auditor de gastos quiero ver todos los gastos del mes actual de modo tal que se presenten al abrir la aplicación y se muestren en una grilla similar a una tabla excel
- Yo como auditor de gastos quiero poder ordenar los gastos de acuerdo a distintos criterios de ordenamiento y que se indique la cantidad de gastos según el filtro aplicado.
- Yo como auditor de gastos quiero ver todos los gastos historicos de modo que pueda elegir el periodo que quiera
