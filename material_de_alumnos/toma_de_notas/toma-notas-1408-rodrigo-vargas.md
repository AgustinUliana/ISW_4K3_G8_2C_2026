# Software Configuration Management (SCM)

Es una disciplina que se encarga de mantener la integridad del software. Seguimiento de los distintos artefactos/ítems de configuración para trabajar sobre la última versión del mismo software

linea base: estado de la configuración que es estable, testeado y asegurando la calidad

Actividades fundamentales:
- Informes de estado
- Control de cambios
- Identificación de ítems
- Auditorias

> [!IMPORTANT]
> El SCM es un proceso super automatizado
